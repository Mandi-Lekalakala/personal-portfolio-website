Amanda's Beauty Bar

RESPONSIVE SALON BOOKING WEBSITE

HTML CSS JavaScript API UI/UX Git/GitHub

The Problem.

Amanda's Beauty Bar needed a professional online presence that reflected the brand's luxury aesthetic while making it easy for clients to browse services and book appointments — without the complexity of a third-party booking platform.

The Process.

I designed and developed the entire frontend from scratch, focusing on clean UI, mobile-first responsiveness, and a seamless booking experience that matched the brand's luxury feel. The site includes a multi-step booking form that guides clients through selecting a service, picking a date from an interactive calendar, choosing a time slot, and confirming their appointment — which then redirects them to WhatsApp with a pre-filled booking message ready to send.

The Result.

A fully responsive multi-page website that strengthened my ability to build real client-facing products, manage multi-page site structure, handle JavaScript DOM manipulation across multiple steps, and translate a brand vision into a polished and functional frontend interface.
