Jobify

AI-POWERED CV & COVER LETTER GENERATOR

HTML CSS JavaScript API AI UI/UX Prompt Engineering Git/GitHub

The Problem.

Job seekers often spend hours tailoring CVs and cover letters for each application, struggling with formatting, tone, and content — a repetitive process that slows down the job search significantly.

The Process.

I built the full frontend structure, UI components, and interactive logic for this AI-powered mini SaaS application. The app features a chat-style interface with state management and user flow, integrating AI-generated responses through API calls. I implemented structured prompt engineering, typing animations, and form validation to create a smooth and natural user experience, focusing on responsive design, dynamic content rendering, and user input handling throughout.

The Result.

A polished, user-focused mini SaaS web application that allows users to generate professional CVs and cover letters in minutes. This project strengthened my ability to manage frontend logic, debug UI behaviour, and build real-world applications from scratch. Please note the application is optimised for desktop only.
